# 🌾 Agri Care Compass

Agri Care Compass is an AI-powered smart agriculture platform designed to support farmers with modern farming solutions. The application provides crop recommendations, weather insights, disease detection, and agricultural guidance to help farmers make informed decisions and improve productivity.

## 📖 Project Overview

Agriculture plays a vital role in the economy, but farmers often face challenges such as unpredictable weather, crop diseases, and lack of timely information. Agri Care Compass addresses these problems by offering a centralized platform that leverages Artificial Intelligence and modern web technologies to provide intelligent farming assistance.

The goal of this project is to make agriculture more efficient, sustainable, and technology-driven by helping farmers make better decisions at every stage of cultivation.

## ✨ Features

- 🌱 Smart Crop Recommendation
- 🌦️ Weather Information and Forecast

- 💊 Fertilizer Recommendations

## 🚀 Project Workflow

1. User registers or logs into the platform.
2. The user enters crop or farm details.
3. The system processes the information.
4. AI models analyze the data.
5. The platform provides recommendations and insights.
6. Farmers can use the suggestions to improve crop productivity.

## 💡 Objectives

- Help farmers make informed agricultural decisions.
- Reduce crop losses through early disease detection.
- Improve productivity using AI-driven recommendations.
- Provide an easy-to-use digital farming platform.
- Encourage smart and sustainable agriculture.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/GuduriAchala08/agri-care-compass.git
```

Navigate to the project

```bash
cd agri-care-compass
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```
